# Experiment R-FL registry

Separate registry for experiment `phase3-rfl`. Independent agents, versions, checkpoints, evaluations, rounds and seals. The original, Experiment 1 and Experiment 1b registries are only read. `metrics/Q2.0.json` is a byte-identical copy of the frozen Q2.0 record.

Blobs: branch `claude/phase3-rfl-artifacts`, checked out at `../../../phase3-rfl-artifacts/blobs` relative to this directory (or set `TRADEWORLD_RFL_BLOBS`).

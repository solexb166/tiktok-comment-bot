The practice markets and what a good agent should do

Hidden pattern, with trading costs

Prices tend to bounce back after each move. A learning agent should spot this and profit after costs, beating random traders that trade as often and as large.

Trend switches it is told about

The market drifts up or down and announces which. The agent should follow the announcement: long in up-trends, short in down-trends.

Pure noise, with trading costs

Nothing to learn and every trade costs money. The right answer is to stop trading.

Pure noise, free trading

Nothing to learn. The agent must not appear to make money: if it did, something would be broken.

Leak trap

Tomorrow's price is hidden in the data where agents must never see it. Any profit would mean the future is leaking in.

Steady gains with sudden crashes

Small gains most of the time, rare 10% crashes. The growth-scored agent should use moderate size (about 3x) and survive. The reckless comparison agent should over-bet and die.

Known best leverage (5x)

A market whose mathematically best position size is exactly 5x. The growth-scored agent should find its way near 5x; the reckless one should not.

How to read this page

Growth per test run is the average change in the account over a 1,000-decision test run (for example +10% means $10 became $11). Deaths is the share of test runs in which the account fell to the 5% floor ($0.50), which ends that agent's run. Average position size is the position's value divided by the account, averaged while the agent is alive (1 means a position the size of the account). Pass and fail use criteria written down before any results came in.

Scoring rules: "Long-term growth" rewards steady compounding, so it punishes big bets that risk ruin. "Reckless (comparison)" rewards raw profit regardless of risk; it exists to show what happens without that discipline.

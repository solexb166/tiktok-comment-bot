# Experiment M4 registry

Separate registry for experiment `phase3-m4` (model-based agents v4, markets that change). Independent agents, versions, checkpoints, evaluations, rounds and seals. All earlier registries are only read. `metrics/Q2.0.json` is a byte-identical copy of the frozen Q2.0 record.

Blobs: branch `claude/phase3-m4-artifacts`, checked out at `../../../phase3-m4-artifacts/blobs` relative to this directory (or set `TRADEWORLD_M4_BLOBS`).

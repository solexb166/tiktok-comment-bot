# Experiment M3 registry

Separate registry for experiment `phase3-m3` (model-based agents v3, trading costs). Independent agents, versions, checkpoints, evaluations, rounds and seals. All earlier registries are only read. `metrics/Q2.0.json` is a byte-identical copy of the frozen Q2.0 record.

Blobs: branch `claude/phase3-m3-artifacts`, checked out at `../../../phase3-m3-artifacts/blobs` relative to this directory (or set `TRADEWORLD_M3_BLOBS`).
